
# Trade & Customs Analytics – Data-Driven Insights for Operational Optimization

## 📌 Project Overview
This project was developed during my Data Analytics Internship with Dataverse Africa. It focuses on analyzing Nigeria’s customs and importation data to uncover inefficiencies, identify risk patterns, and recommend data-backed improvements in trade operations, taxation, and compliance.

## 🎯 Objectives
- Improve import volume and tax revenue tracking
- Optimize container usage and logistics operations
- Strengthen risk-based monitoring for high-risk countries
- Support policy decisions and trade diversification through data

## 🔧 Tools & Technologies
- Excel  
- Power Query  
- Python (Pandas, NumPy)  
- Power BI  

## 🧼 Data Cleaning Summary
Detailed data cleaning was conducted using Excel, Python, and Power Query:
- Missing values handled via median/mode substitution or labeled as "Unknown"
- Date fields standardized and converted to datetime
- Winsorization applied to top 17% of extreme values for CIF, FOB, Tax, and Weight
- Country names and formats normalized
- Data types aligned for accurate modeling

## 📊 Key Insights
- CIF and FOB values have a near-perfect correlation (0.99), influencing tax calculations  
- Heavier shipments generally attract more tax, though container count does not correlate strongly with shipment value  
- Certain customs offices (e.g., NT and MP Office) handle significantly higher volumes and warrant stricter oversight  
- Imports from high-risk countries like China and India require better screening processes  

## 🧠 Recommendations
- Automate tax calculations and monitoring in high-volume customs offices  
- Improve logistics with shipment forecasting and container optimization  
- Develop a centralized monitoring platform and implement predictive analytics  
- Introduce real-time compliance alerts for delayed payments or suspicious shipments
